# Sailor · Display & Requirement Planner

আউটলেটের স্টাফদের জন্য মোবাইল অ্যাপ (Refill Monitor-এর মতো):
- **Display list**: কোন স্টাইল-কালার ডিসপ্লে করতে হবে, সেই লিস্ট। সব সাইজ আছে এমনগুলো প্রথমে আসে, তারপর XXL নেই, তারপর XXL ও S নেই, এভাবে।
- **Scan**: Display-এ যে সেকশন সিলেক্ট করা আছে, তার সাথে মিলিয়ে বারকোড স্ক্যান করলেই বলে দেয় পণ্যটি **DISPLAY** হবে, **KEEP IN STORE** থাকবে, নাকি **OTHER SECTION**-এর। সাথে পণ্যের সব ডিটেলস দেখায়। DISPLAY পণ্য Display list-এ নিজে থেকেই টিক হয়ে যায়।
- **Requirement**: গত ১০ থেকে ৬০ দিনের সেল থেকে কোন পণ্যের কত পিস রিকোয়ারমেন্ট দিতে হবে, তার লিস্ট। Excel ও PDF-এ ডাউনলোড করা যায়।

অ্যাপের ভেতরের সব লেখা ইংরেজিতে।

## প্রথমবার সেটআপ (একবারই করতে হবে)
1. GitHub-এ নতুন একটি repository খুলুন, যেমন `sailor-planner` (Public)।
2. **Add file → Upload files**-এ এই ফোল্ডারের সব ফাইল দিন (`lib` ফোল্ডারসহ), তারপর **Commit changes**।
3. **Settings → Pages → Branch: main / (root) → Save**। ১-২ মিনিট পর লিংক চালু হবে:
   `https://mirpur2sailor-max.github.io/sailor-planner/`
4. স্টাফদের লিংকটি দিন। মোবাইলে Chrome-এ খুলে মেনু থেকে **Add to Home screen** দিলে অ্যাপের মতো চলবে।
   প্রথমবার access code চাইবে (Refill Monitor-এর একই কোড)।

## প্রতিদিন ডাটা আপডেট
1. আগের মতোই একটি Excel ফাইল রাখুন, যেখানে **Stock Data** শিট ও **Sales Data** শিট থাকবে
   (অথবা দুটি আলাদা ফাইল, দুটো একসাথে সিলেক্ট করবেন)।
2. কম্পিউটারে Chrome-এ খুলুন: `…/sailor-planner/publisher.html`
3. ফাইলটি সিলেক্ট করুন → access code দুবার লিখুন → **Create data.dat** → **Download data.dat**।
4. GitHub repository-তে **Add file → Upload files** → `data.dat` দিন → **Commit changes**।
5. ১-২ মিনিট পর স্টাফরা অ্যাপ খুললেই নতুন ডাটা পেয়ে যাবে।

সেলস শিটে যতদিনের ডাটা থাকবে, অ্যাপ সেটাই নেবে। ৬০ দিনের ডাটা দিলে ৫০ ও ৬০ দিনের অপশনও চালু হয়ে যাবে।

## হিসাব কীভাবে হয়
- **সাইজ রান**: স্টক রিপোর্টে একটি স্টাইল (যেকোনো কালারে) যত সাইজে এসেছে, সেটাই তার পুরো সাইজ রান।
- **Display priority**: যে সাইজগুলো সিলেক্ট করা আছে, সেগুলো স্টকে থাকতেই হবে। কম সাইজ মিসিং হলে আগে আসে।
  একই সংখ্যক সাইজ মিসিং হলে XXL মিসিং আগে, তারপর S, তারপর বাকিগুলো।
- **Requirement** = (নির্বাচিত দিনে বিক্রি ÷ দিন × cover দিন, উপরের দিকে রাউন্ড করে) − বর্তমান স্টক।
  Net sale = SQTY − RQTY − EXG_QTY।
- টিক দেওয়া তথ্য প্রতিটি মোবাইলে আলাদাভাবে সেভ থাকে।

## স্ক্যানিং টিপস (স্টাফদের জানিয়ে দিন)
- বারকোডটি বাক্সের ভেতরে আড়াআড়ি রাখুন, ফোন ১০–২০ সেমি দূরে রাখুন।
- খুব কাছে নিলে ঝাপসা হয়। একটু দূরে রেখে **1.5× / 2×** জুম বাটন চাপুন (যেসব ফোনে আছে)।
- আলো কম হলে 💡 ফ্ল্যাশ বাটন চাপুন।
- একাধিক ব্যাক ক্যামেরা থাকলে ⟳ বাটন দিয়ে ক্যামেরা বদলানো যায়। যেটায় ভালো হয় সেটা অ্যাপ মনে রাখে।
- একেবারেই না হলে **Scan from photo** চাপুন: ফোনের নিজের ক্যামেরা অটোফোকাস করে ছবি তোলে, সেই ছবি থেকে পড়ে নেয়।
- হাতে লিখেও বারকোড দেওয়া যায়, আর USB/ব্লুটুথ বারকোড স্ক্যানারও ওই ঘরে কাজ করে।
