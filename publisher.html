Data Publisher

Turn today's stock report and the sales report into one encrypted data.dat. Upload it to GitHub and every employee's Display & Requirement app updates itself.

1. Choose the report file(s)

One workbook with both sheets (Stock Data + Sales Data), or two separate files: select both together.

0pieces in stock
0pieces sold

2. Name and access code

If you change the code, every employee has to enter the new code once.

Download data.dat

3. Publish on GitHub

  1. Save data.dat. If the browser named it data (1).dat, rename it to exactly data.dat.
  2. Open the app's GitHub repository → Add file → Upload files → drop data.dat → Commit changes. It replaces yesterday's file.
  3. Wait 1–2 minutes. Staff open the app as usual; it picks up the new data by itself.
